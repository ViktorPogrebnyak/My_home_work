# Домашняя работа 4 — REST Assured

В проект добавлены тесты учебного API для эндпоинтов товаров и задача Gradle `apiTest`.

## Запуск учебного API

Запустите предоставленный JAR на порту `8080` через IntelliJ IDEA: **Run → Edit Configurations → + → JAR Application**, укажите JAR-файл и нажмите **Run**. Оставьте окно приложения запущенным, пока выполняются тесты.

## Запуск тестов

В конфигурации Gradle или в терминале задайте переменные среды `API_USERNAME` и `API_PASSWORD` со значениями учётной записи учебного API. При необходимости адрес API можно переопределить переменной `API_BASE_URL` (по умолчанию `http://localhost:8080`).

Затем запустите задачу **Gradle → Tasks → verification → apiTest**. Она запускает только тесты с тегом `api`.

Тесты проверяют документированные коды `200`, `400` и `404` для соответствующих операций; `500` не включён, поскольку в условии он не считается штатным ответом. Тестовые товары создаются со случайными именами и удаляются после каждого теста.
